# Installation and delivery checklist
[中文](installation-checklist.md) · [Get started](getting-started.en.md)

These are manual review steps. Ticking a box is not an automated test.

- [ ] Download a named release and compare the files with its SHA256SUMS.txt.
- [ ] Keep the whole skill folder, including SKILL.md, references, assets and any scripts.
- [ ] Choose a skills directory supported by your tool. If discovery is unclear, ask the assistant to read SKILL.md directly.
- [ ] Back up an existing folder before replacing it.
- [ ] Provide the topic, reader, sources, output language, format and material to preserve.
- [ ] Confirm an image tool is available. Install requirements.txt if rebuilding the example PDFs.
- [ ] Try a small task and confirm the assistant actually used the instructions.
- [ ] Check facts, sources, image-to-text relationships, readable type and page count.
- [ ] Keep editable content, artwork, full prompts and layout source with the export.
- [ ] Check the licenses for fonts, images and third-party material.
- [ ] Read the untested items in the verification record; repeat affected checks after an update.

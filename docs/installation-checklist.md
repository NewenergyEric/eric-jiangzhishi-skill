# 安装与交付检查清单

[English](installation-checklist.en.md)

这些是用户验收步骤，不代表勾上就已经通过程序测试。

- [ ] 下载来自本仓库的明确版本，核对 Release 中的 SHA256SUMS.txt。
- [ ] 保留完整 Skill 目录，确认 SKILL.md、references、assets，以及该 Skill 提供的 scripts 都在。
- [ ] 选择合适的宿主和技能目录；不能确定自动发现规则时，让助手直接读取 SKILL.md。
- [ ] 已有同名目录时先备份，不直接覆盖。
- [ ] 准备主题、读者、资料、输出范围和保留项。
- [ ] 制图环境可用；如果重建案例，Python 与 requirements.txt 已满足。
- [ ] 用一个小任务确认助手实际读到了方法，不把文件存在当作加载证明。
- [ ] 检查事实、来源、图文关系、真实字号和导出页数。
- [ ] 确认可编辑内容、插画、完整提示与排版源一同交付。
- [ ] 复查字体、图片与第三方材料的许可范围。
- [ ] 阅读验证记录中的未测项；更新版本后重新检查受影响环节。

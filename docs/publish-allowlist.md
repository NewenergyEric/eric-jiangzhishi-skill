# 公开发布范围

「一起读懂 / Making Sense Together」发布两个自包含 Skill，以及「太阳系八大行星」与「认识细胞」两个案例，各两页。另附横屏 16:9、竖版 9:16、方版 1:1 的中英文 16 秒介绍视频、GIF、海报与源码。

允许进入提交与发布包的范围：

- 根目录的 README、MIT 许可、第三方说明、版本、依赖与 Git 忽略规则。
- `skills/`：两个 Skill 的说明、英文简介、通用参考、模板、检查脚本与太阳系案例的轻量样页。
- `examples/solar-system/`、`examples/cells/`：原创文字、英文译文、双语阅读版、来源、制作过程、完整生成提示、模型插画、手写标题、中英文两页 PDF、逐页 PNG 和英文排版记录。
- `media/badges/`：首页使用的四个原创 SVG 介绍标签。
- `media/intro/`：六组 MP4、GIF、静态封面与海报，以及共享分镜、比例设置、布局检查、输出报告和重建说明。
- `docs/`：中英文上手入口、安装清单、发布范围、验证记录。
- `scripts/`：本项目构建、打包、引用与脱敏检查脚本。
- `vendor/fonts/`：可再分发的开放字体及其原许可。

`.build/`、`dist/`、缓存和中间日志不进入 Git；`dist/` 中经过核对的 ZIP 可作为 Release 附件。以最终 `git ls-files` 与 ZIP 成员清单再次核对，不直接上传整个工作目录。

不纳入：旧商品整页、原参考书、旧网站、原品牌资产、联系方式、聊天记录、内部部署信息、认证信息、历史日志或其他项目资料。扫描只针对上述候选文件、导出媒体和本项目提交树；报告只记录规则与文件位置，不记录命中的敏感值。

公开提交仅使用经当前 GitHub 账号核对的 noreply 邮箱。字体沿用其原许可；外部权威资料仅引用链接和原创转述，不将第三方内容改标为本项目所有。

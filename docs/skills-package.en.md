# Making Sense Together: two independent skills
[中文](skills-package.md)

- [Content & explanation](../skills/knowledge-to-friendly-product/README.en.md) turns sources into a connected explanation and can carry the project through to illustrated pages.
- [Illustration & layout](../skills/knowledge-card-art-direction/README.en.md) starts with approved copy and works on the artwork, typesetting, proofing and export.

Copy the entire chosen folder into a skills directory supported by your tool. Then confirm the tool can find it, or ask the assistant to read SKILL.md directly. Each folder contains its own references and assets. Neither requires the other.

SKILL.md remains the instruction entry. The English overview is for readers; it does not create a third skill. Ask for output in English or another language.

This archive contains methods and helper scripts. It does not install Python, run image generation or publish anything. Download the full archive from the same release for complete examples, PDFs, videos, the font and build scripts.

The lightweight previews show the Chinese solar-system example. Original methods, code and material this project can license use [MIT](../LICENSE). AI-generated artwork does not imply exclusive copyright.

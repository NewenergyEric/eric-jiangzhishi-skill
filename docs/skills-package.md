# 两个可独立安装的 Skill

从资料理解到完整图文，用 [knowledge-to-friendly-product](../skills/knowledge-to-friendly-product/SKILL.md)。

内容已定后的插画和排版，用 [knowledge-card-art-direction](../skills/knowledge-card-art-direction/SKILL.md)。

复制整个 Skill 目录到你所用宿主支持的位置，再确认宿主已经识别它。每个目录内的参考与脚本都能独立使用；两个 Skill 不需要彼此安装。目录中的太阳系样页只用于展示相同的一份两页案例。

这是方法与辅助脚本包，不会自动安装 Python、启动生图或对外发布。需要完整案例、PDF、字体和构建源时，下载同一 Release 中不带复数 skills 后缀的完整包。

原创方法、代码、太阳系图像和文字按 [MIT](../LICENSE) 提供本项目可授予的使用权；AI 生成图像不代表排他版权。包内不含魔兽世界主题插画或第三方字体文件。

# 实际验证记录

版本：1.0.0。日期：2026-10-12。检查对象是本公开项目及其发布白名单，未扫描或复制其他项目。

| 范围 | 实际做法与结果 |
|---|---|
| 知识来源 | 太阳系逐项核对 NASA 与 IAU；魔兽按当日国服公告核对六条编辑分组、测试状态与奥杜尔阶段。来源表记录具体主张。 |
| 两个独立 Skill | 分别复制到全新临时目录，12 / 13 个文件逐字节相同；目录内引用与预览均有效。再次安装同名目录会停止，原文件没有改变。 |
| 辅助检查脚本 | 内容相同通过；故意改值或删项会失败。布局中的过小字号、越界与碰撞均能被负例检出。实际两份布局清单通过。 |
| PDF 与图片 | 每例严格两页，720 × 960 pt；逐页 PNG 为1440 × 1920。正文17 / 18 pt，图注13 pt，行星标签15 / 16 pt。PDF抽取文字与正文源匹配。四页均目视查看。 |
| 美术修订 | 已检查生成标题字形、图标风格、行星顺序、图注对应关系。魔兽图注移到留白；血精灵建筑加强红金曲面屋顶、细长拱廊和奥术构件。 |
| HTML | 阅读版由同一正文源生成。上手入口的选择切换、复制成功及失败回退、清单计数与重置通过独立 JavaScript 逻辑检查。 |
| 媒体与脱敏 | PNG移除元数据前后像素哈希相同；检查PDF文字与元数据；扫描白名单中的本机路径、认证值、会话标识、私钥和联系邮箱。字体原许可中的公开作者信息保留。规则报告不输出命中的敏感值。 |
| 发布包 | 完整ZIP在独立目录解压后通过引用、媒体与脱敏检查；在相同依赖版本下重新构建，两份PDF和四张PNG逐字节一致。Skills小包独立解压后内部引用有效；从完整包运行安装辅助也成功。 |
| Git 提交树 | 在独立新仓库暂存73个白名单文件，实际暂存字节与公开文件逐项一致；不继承旧仓库历史。提交身份使用本账号的 GitHub noreply 邮箱。 |

公开文件的准确清单见 [publish-files.json](../publish-files.json)。ZIP 只从该清单生成；Skills 包另取其中两个 Skill、项目许可、版本与简短说明。构建缓存、候选图、临时测试、原项目资料和历史日志不进入包。

自动脚本可重新运行：

```sh
python scripts/verify_project.py
python scripts/verify_project.py --staged
python scripts/package_release.py
```

第二条需要 Git 暂存区；它逐文件核对清单和实际暂存字节。发布资产另附 SHA256SUMS.txt。模式扫描不是对所有形式敏感信息的数学保证，仍需结合来源边界与文件目视检查。

隔离复现时发现并修正了字体实例的生成时间以及依赖文件位置的图像编号。字体缓存保留上游字体的固定时间信息，图像编号基于内容，因此换目录重建不再仅因路径变化而改变 PDF。跨依赖版本的逐字节一致性未验证。

## 未验证的部分

- 未做真实目标读者试读、天文学专家审稿或游戏客户端实测。
- 未验证每一种宿主的 Skill 自动加载；目录安装成功不等于宿主已经发现。
- 内置浏览器无法访问本地 HTTP 服务，其安全策略也不允许 file URL；未绕过限制。HTML做了引用和逻辑检查，未把桌面或手机浏览器实际渲染列为通过。
- 未用屏幕阅读器测试 PDF。生成标题另有搜索文字层，完整文字阅读版可选取内容；这不等于 PDF/UA 合规认证。
- 图像模型输出不保证逐像素重现。已附采用素材用于排版复现，早期未采用候选未公开。
- 魔兽地点为同人意象；第三方游戏元素不在本项目 MIT 授权范围，详见 [许可与素材](../THIRD_PARTY_NOTICES.md)。

## 重新检查

```sh
python scripts/verify_project.py
python scripts/verify_project.py --staged
python scripts/package_release.py
```

第二条逐文件核对 Git 暂存字节与白名单。发布附件另附 SHA256SUMS.txt。ZIP 不包含构建缓存、候选图片、其他项目资料或历史日志。

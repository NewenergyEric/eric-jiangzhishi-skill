## 重新检查

```sh
python scripts/verify_project.py
python scripts/verify_project.py --staged
python scripts/package_release.py
```

第二条逐文件比较 Git 暂存内容与公开清单。打包只读取清单中的文件，不包含构建缓存或其他项目资料。

## 检查的边界

- 未做生物学专家审稿或真实读者试读，也未验证所有宿主的 Skill 自动发现。
- 本地 HTML 受内置浏览器访问限制，做了链接和逻辑检查，未验证浏览器实际渲染及播放器交互。
- 视频做了完整解码和实际编码文件抽帧查看；未验证社交平台上传后的转码和显示。
- 原 PDF、图片标题与图内文字保留中文；英文阅读版完整翻译正文，未另做英文图文 PDF。
- 未做 PDF/UA 认证或屏幕阅读器实测。采用图片已随包提供；图像模型不保证逐像素重现，跨依赖版本的 PDF 字节一致性未验证。

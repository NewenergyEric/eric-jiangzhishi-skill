# 太阳系案例：来源与事实核对

核验日期：2026-10-12。以 NASA Science 和国际天文学联合会（IAU）一手资料为依据，使用原创中文转述，未打包原网页、机构图片或参考书。

| ID | 一手资料与定位 | 本案例采用的事实 |
|---|---|---|
| S01 | [NASA · About the Planets](https://science.nasa.gov/solar-system/planets/)，Inner / Outer Planets | 八颗行星的名称与从太阳向外的顺序；内侧四颗为类地行星；木土为气态巨行星，天海为冰巨行星 |
| S02 | [NASA · Solar System Facts](https://science.nasa.gov/solar-system/solar-system-facts/)，Introduction / Size and Distance / Structure | 太阳是一颗恒星；太阳系位于银河系内；太阳系范围远超海王星轨道；主小行星带位于火星与木星之间 |
| S03 | [NASA · Mercury Facts](https://science.nasa.gov/mercury/facts/)，Introduction / Surface | 水星最靠近太阳、体积最小，表面有许多撞击坑 |
| S04 | [NASA · Venus Facts](https://science.nasa.gov/venus/venus-facts/)，Introduction / Atmosphere | 金星浓厚大气造成强烈温室效应，是最热的行星 |
| S05 | [NASA · Facts About Earth](https://science.nasa.gov/earth/facts/)，Introduction / Potential for Life | 地球有广阔海洋，是从太阳数第三颗行星 |
| S06 | [NASA · Mars Facts](https://science.nasa.gov/mars/facts/)，Namesake | 火星的红色与土壤里铁矿物氧化有关 |
| S07 | [NASA · Jupiter Facts](https://science.nasa.gov/jupiter/jupiter-facts/)，Introduction / Structure | 木星最大，条纹是云带，大红斑是风暴；主体富含氢和氦 |
| S08 | [NASA · Saturn Facts](https://science.nasa.gov/saturn/facts/)，Rings / Structure / Surface | 环由大量冰与岩石颗粒构成；土星富含氢氦，没有地球式固体表面 |
| S09 | [NASA · Uranus Facts](https://science.nasa.gov/uranus/facts/)，Orbit and Rotation / Structure | 天王星近乎侧躺自转；冰巨行星内部并非冻结的冰球，而有高温高压下的水、氨、甲烷等物质 |
| S10 | [NASA · Neptune Facts](https://science.nasa.gov/neptune/neptune-facts/)，Orbit and Rotation / Structure | 海王星为第八颗行星，公转周期约165个地球年；属于冰巨行星 |
| S11 | [IAU · 2006 Resolution Votes](https://www.iau.org/IAU/Iau/News/PR2006/iau-2006-general-assembly-resolution-votes.aspx)，Definition of a Planet / Pluto | 太阳系行星与矮行星是不同类别；冥王星属于矮行星 |

“向外旅行”是原创叙事组织，不是航天路线。图片为模型生成的艺术示意：大小、距离、颜色和曲线均做过简化，不表示当前天体位置；也没有画出全部卫星与环。没有把太阳算进行星，没有把冥王星作为第九颗行星，没有把海王星轨道当作太阳系边界。

未使用会频繁变化的卫星数量、精确排名外的临时纪录或尚未确定的第九行星假说。科学分类和正文经资料核对与模型自检；没有进行天文学专家审稿或真实读者试读。

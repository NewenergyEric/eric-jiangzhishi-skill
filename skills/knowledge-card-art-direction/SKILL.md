# 一起读懂 · 插画排版

[English overview](README.en.md)

按用户指定语言工作。原有案例为中文，新的内容和排版应适配任务要求的语言。

从用户已经认可的内容和风格开始，确认保留项、可变项和交付形式。不要自动改成书、演示文稿或课程。

## 内容、图像、排版各管什么

冻结唯一正文源并记录哈希。用户允许改写时保存必要的 before / after / reason；以最新授权为准。检查主题、解释、例子、来源和边界，排版不得偷偷增加事实或删去条件。

图像模型负责可见对象、关系、材质和动作。正文、数据、精确标签、页序和链接由程序或排版工具完成。生成图里的额外文案只是草图噪声，不能成为事实来源。已有品牌资产只有在确认可用且本项目需要时才复用。

## 先组织阅读，再选布局

读 [布局与文字适配](references/layout-and-type.md)。让读者顺着自然句子理解内容，不用“标题、定义、三点总结”替代解释。可以使用 [暖纸手绘预设](assets/style-preset.json)，也可以替换为用户指定风格。

画风固定，镜头、主体大小、留白和图文穿插随关系变化。不要每页都做成几个一样大的方框，不让无关吉祥物替所有知识发言。

已有可用样板可直接继续；新方向先完成代表性构图，再归纳规则。样板数量按项目决定，不为两页内容制造额外案例或封面。

## 生成、制版与复核

读 [模型插画约定](references/model-first.md)，主插画用可用的图像模型，准确中文另排。模型不可用时明确缺少实际插画，交付提示和分镜，不用机械拼图假装已完成。

记录实际观看尺寸和字号下限。测量真实字形边界、文本区、图内安全区与换行。正文放不下先调整句意、宽度、图的占比或结构，不能一直缩字。把小图内的长标签移到图外也可以。

使用 [内容锁定脚本](scripts/check_content_lock.py) 比较基线与候选文件；使用 [布局检查脚本](scripts/check_layout.py) 检查实际文字位置清单。脚本只需 Python 标准库，输入格式见 [检查说明](references/checks.md)。失败时定位原因，不以重写基线绕过差异。

导出成功后，从真正交付的 PDF 渲染预览，检查每页和密集区域。自动检查不能识别插画中的所有碰撞，也不能证明语义正确。检查结果分别记录自动核验、模型目视与真实用户反馈。

## 可接续交付

交付成品、可编辑内容和排版源、采用插画、完整提示、样式参数、来源及检查结论。品牌、字体和第三方素材分别确认分发范围。不附旧项目私密资料、整本参考书或无授权图像。

[两页公开案例](references/solar-system-case.md) 和 [安装验收清单](references/installation.md) 随包可读。本 Skill 可单独安装；它不会自动运行脚本、联网、生图或发布。

# 安装与验收

1. 从项目 Release 下载公开包并解压，核对版本与校验清单。
2. 把所需 Skill 的整个目录复制到你的 AI 工具支持的技能目录；不要只复制 SKILL.md。
3. 不确定宿主规则时，直接让能读文件的助手读取这个目录中的 SKILL.md。目录存在不代表宿主已自动发现或加载。
4. 给出主题、具体读者、资料、载体与页数、风格和不可改项。先用一份小任务检查理解。
5. 制图需要图像模型，制版需要相应工具；缺少能力时记录实际限制。
6. 验收文字来源、图文一致性、实际字号、交付文件和可编辑源。
7. 更新同名旧版前先备份；需要移除时只移走本 Skill 目录。

公开包验证了独立解压、内部文件引用和辅助脚本。没有在每一种宿主中自动加载；其他主题的效果也未经过普遍验证。勾选清单不等于程序验收。

最短请求：

> 读取这个目录的 SKILL.md。主题是【主题】，读者是【已有知识和阅读情境】，资料是【文件或链接】。请完成【载体与页数】，沿用【风格】，先核验事实，再做自然连贯的图文表达，交付成品、源文件和实际检查记录。

# 布局与真实字号

| 需要说明的关系 | 可选组织方式 | 容易出现的误读 |
|---|---|---|
| 多路径与分流 | 漫游图、位置网络 | 画成唯一通关路线 |
| 两种解释或处境 | 不等大的对照 | 简化成好与坏 |
| 条件组成 | 拆解台、部件关系 | 画成不存在的定量公式 |
| 过程与顺序 | 连续线路、沿途旁白 | 把示意线当实际轨道 |
| 生活中的理解 | 小剧场、近景与旁白 | 让道具抢走知识重点 |

无需凑齐形式。相邻页保持色彩、材质和层级即可，不必固定每个区块位置。短篇正文用连续段落留住因果，标题不必每段出现。

先确定输出尺寸和观看方式。示例 PDF 为 720 × 960 pt，正文 17–18 pt，导出 1440 × 1920 px；这是本案例选择，不是所有项目的规定。手机整页缩放后仍可能小，应提供放大或同内容流式文本。

适配顺序：删无意义重复但保留条件 → 调整宽度、行距、分栏和留白 → 调整图的尺度与位置 → 将长标签移到图外 → 必要时调整载体。不能无限缩字。

记录实际换行、字号、行距、分配高度和字形墨迹边界。小牌面另设可用内框；整页不溢出不代表牌面内不碰框。旋转标签的字形边界也要旋转。中英文与数字分别校样。

避免右引号和句末标点独占行首、左引号挂行尾、英文从词中切开、标题最后一行剩孤字。优先重新分配字数，不通过挤压字距解决。

看导出文件中的完整阅读顺序、空白、对比度、图文接触与脚注。自动检查和目视分别记录，不把检查成功说成用户批准。

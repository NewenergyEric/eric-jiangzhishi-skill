# 模型插画约定

标题字形可以单独生成，保留透明字图和完整文字源，逐字核对形、序与标点。它是图片素材，不是可安装字体。正文继续用可读字体排版；语义文字同步到可选择的阅读版。

图标要与主体同一画风，并承担引路、标记或解释作用。先决定图标含义，再生成少量配套图标；不要混用系统 emoji、金属拟物图标和暖纸手绘。实际尺寸下仍要能辨认。

若主题需要辨识特定地点或物品，先核对相关事实再画，用图注连上主题。游戏同人插画应准确区分独立生成、官方素材和第三方设定权利；不声称已获未取得的授权。

提示顺序：用途 → 参考角色 → 固定画风 → 本次知识关系和对象 → 构图及文字安全区 → 排除项。

一张图服务一个主要关系。写出可见对象及其数量、位置、动作、遮挡和对应的知识，而不只堆风格词。style、identity、composition 各管什么要清楚。

正文与精确标签通常不让图像模型生成。有意义的牌面可以留白供制版填写，无含义的空牌子不放。完整页面生成可用于构图探索，但不是已校对产品。

主图使用可用图像模型。程序负责版面和必要连接线，不替代主图。若模型不可用，交付文字和提示并如实说明限制。

保存原始输出、公开采用副本、完整提示、已知工具/模型标识和目视结果。工具没有暴露模型版本就如实记录未知。公开副本可以清除 EXIF、PNG 文本块等非必要元数据；保留图像像素和来源说明。

检查对象数量与特征、关系、额外文字、透明边缘和版权来源。首次生成不合适时，针对问题修订而非重复换一整套风格。生成照片与艺术示意不能冒充观测证据。

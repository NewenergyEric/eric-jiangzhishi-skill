# Content & explanation
**Making Sense Together · 一起读懂**

Skill ID: `knowledge-to-friendly-product` · [Instruction entry in Chinese](SKILL.md)

Use this when you have sources and a question but have not yet worked out how to explain it. It covers research, writing, illustrations, layout and a handoff you can keep editing. It can work on its own.

## Bring these inputs

A topic, the reader's background, the reading context, source files or links, output language, format and page count. Add any style references and material that must not change.

## How it works

1. Read the actual sources and existing work. Keep the decisions the user has already made.
2. Separate established facts from research findings, models, rules of thumb and invented examples. Check primary sources where possible and keep claims linked to them.
3. Build the explanation around a reader's question. Preserve causes, conditions, uncertainty and exceptions. Explain necessary terms when they appear.
4. Choose images that show the relevant relationship. Keep an agreed visual style while allowing each page to use the space differently.
5. Typeset precise copy and labels separately from generated artwork. Review the actual export, then hand over both the result and its editable source.

New illustrations need an available image-generation tool. If it is missing, the assistant should deliver the writing, scene plan and prompts, and say that the images are still needed.

## Try it

> Read this folder's SKILL.md. Make a two-page English guide to cells from my sources for a reader new to biology. Explain how the parts work together, then compare animal, plant and bacterial cells. Use warm hand-drawn artwork and readable body text. Keep the sources, full prompts, artwork and layout source.

The included [style preset](assets/style-preset.json) is optional. [Page one](assets/example-page-01.png) and [page two](assets/example-page-02.png) show the original Chinese solar-system example.

## Install and review

Copy the whole folder into a skills directory your assistant supports, or ask it to read SKILL.md directly. No Python installation is needed to read these methods. Confirm host discovery with a small task; file copying alone does not prove it was loaded.

Keep the finished pages, editable copy, selected artwork, generation prompts, style settings, sources and actual check results. The skill does not authorize external publishing. [Installation details in Chinese](references/installation.md) · [MIT license](LICENSE).

# 图像与交付

标题可由模型生成适合内容的手写字形，逐字校对后作为独立图片使用，同时保留可搜索的文本或 HTML 文字版。标题字图不是完整字库，不给正文套用难以辨认的装饰字。

巧用图标帮助读者找路：图标应提示真实内容，例如望远镜对应观察、罗盘对应选择、沙漏对应时间。沿用主插画的笔触、色板和材质，不混搭默认 emoji 或无关装饰。每页少量即可，不为每段强配一个图标。

主题有可识别的地点、器物或时代特征时，用代表景物建立联系，并配准确图注；不要用通用幻想图代替需要辨识的对象。涉及已有游戏或品牌时单独说明素材与第三方权利，不把生成图片等同于获得原设定授权。

固定色板、线条起伏、纸张质感、人物尺度与情绪，允许构图随知识关系变化。style 参考管笔触和材质；identity 管必须保留的角色或物件；composition 管明确需要保留的空间组织。不要因为给了参考图，就把它的商标和道具一并复制。

主图用于表现关系、动作和可见特征。准确文字与数字另排。提示说明用途、约束、画面对象、构图、文字留白、排除项，并保存完整版本。检查实际输出：对象数量、顺序、形态、前后遮挡和额外文字，不能把提示写对当成图画对。

同一画风不等于相同布局。比较适合不等大的对照场；分流适合漫游图；过程适合连续线路；情境适合小剧场。只选有用的形式。相邻页面重复时先检查关系是否真的相同。

先确定实际观看方式，再设正文和标签字号下限。整页缩到手机宽度会同时缩小文字；高分辨率不能解决字太小。固定页面提供放大查看入口，手机优先时加同内容的单栏阅读。检查中文行首标点、尾行孤字、字形外伸、图内牌面和文字遮挡。空间不足先改布局。

交付复核分五项：

| 项目 | 实际要查 | 不能扩大成的承诺 |
|---|---|---|
| 知识 | 来源、条件、边界、图中关系 | 有链接就全部正确 |
| 表达 | 指代、术语、叙事是否可理解 | 模型自检等于读者试读 |
| 图文 | 对象、标签、序号和说明对应 | 生成模型自动懂科学 |
| 阅读 | 导出后的大小、留白与溢出 | 源文件通过就排版合格 |
| 文件 | 页数、链接、素材、可编辑源一致 | 解压成功等于运行器已加载 |

等导出进程成功结束，再从同一 PDF 渲染预览，记录哈希以避免新旧混用。全量看图、放大读字；必要时修订并重新导出全部受影响载体。

保留简洁项目说明、来源台账、原创文字、风格参数、原图、完整提示、排版源和验证记录。资料仅引用或合法授权使用；不要附原书扫描件、历史客户资料、私人路径、联系方式和令牌。发布白名单及最终 Git 树应一致。

产品介绍说清谁会用、需要什么、会得到什么，展示实际样页。知识内容、宣传文案与交易设置分开，推广不能改变知识结论或制造效果保证。

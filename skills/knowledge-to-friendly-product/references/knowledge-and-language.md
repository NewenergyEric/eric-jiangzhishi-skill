# 知识先弄懂，句子再写顺

先辨认资料是作者主张、引用研究、例子还是自己的推断。用自己的话解释：“哪些对象在什么条件下，通过什么关系，影响了什么；这不意味着什么。”纯分类主题不强行编造因果，改为说明分类依据和边界。

一个单元解决一个可辨认的问题。建议保留 `knowledge_id / reader_question / mechanism_or_relation / example / judgement / boundary / source_id`。来源台账包含机构、标题、URL 或章节、核验日期和支持的具体主张。数量不是质量；相关性不能被画成确定因果。

把相似单元并排看场景、关系和产出，全部相同就合并。保留概率、否定、时间范围、前提和例外。内容锁定只证明文件没变，不证明内容正确。

确定读者当时知道什么、困惑什么、有多少注意力。普通读者也值得得到完整解释。亲切可以有趣，但不幼儿化，不用责备制造“共鸣”。术语后接一句普通话，不用另一个更难的术语解释它。

连续叙述示例：

> 水星离太阳最近。金星虽然在更外面，却因为浓厚大气造成的强烈温室效应，比水星还热。

它把空间顺序、温度反差和原因接在一起。制作记录可以拆成字段，读者页面不需要把这些字段逐个展示。

比喻先写对应关系与不能对应的部分。例如“向外旅行”只组织阅读顺序，并不声称行星排成直线、距离均匀或飞船能这样直飞。真实比例另画比例图；艺术示意明确标注。

改写已认可内容，记录 before / after / reason。若仅允许视觉调整，保留正文；用户后来授权语言修订，以最新范围为准。朗读或默读能发现生硬句子，但只是作者自检。没有真实目标读者参与，不写“读者测试通过”。
